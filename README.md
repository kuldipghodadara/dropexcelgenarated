# Dropbox SKU Excel Generator

A lightweight, clean Electron application for generating an Excel catalog of SKUs by extracting shared links for images stored in Dropbox.

## Features
- Connect securely to Dropbox using an access token.
- Visually navigate your Dropbox folders.
- Auto-scan SKU subfolders for numbered images.
- Automatically generate Dropbox shared links for each image.
- Export results instantly to a well-formatted Excel file.

## Setup
1. Run `npm install` to install dependencies.
2. Run `npm start` to launch the application.

*No Python dependencies are required.*
